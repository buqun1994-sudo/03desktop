# 验证矩阵

## 1. 当前入口

1. 项目初始化与 skill：`node scripts/check-project-ready.mjs && node scripts/check-skills.mjs`。
2. Android 配置与权限：`node scripts/check-android-config.mjs`。
3. 工具链：`./scripts/check-android-env.sh`；需要连接车机时追加 `--device`。
4. 单测、Lint 与构建：`./scripts/gradlew-jdk17.sh testDebugUnitTest lintDebug assembleDebug`。
5. 车机系统入口只读探测：`./scripts/check-device-capabilities.sh --package <普通第三方应用包名>`。
6. 文档/空白：`git diff --check`；未提交新仓库还需用源码扫描确认没有本机绝对路径或敏感材料。

## 2. 变更分级

| 变更类型 | 必须验证 |
|---|---|
| 只读查询 | 不默认跑构建；记录实际查询范围与是否改设备 |
| 文档、目录、初始化底座 | 项目就绪、skills、Android 配置、环境、`git diff --check` |
| Gradle、Manifest、资源、Kotlin | Android 配置、单测、Lint、Debug 构建 |
| 领域纯函数、排序、事件合并 | 相关边界单测 + 全部 Debug 单测 |
| 悬浮窗口、手势、网格、拖拽 | 构建 + `S56_HQX` 坐标/跟手/触摸/泄漏运行 smoke |
| 应用枚举、启动、包广播 | 单测 + UI/ADB 基线比对 + 启动和刷新真机 smoke |
| APK 存储与系统安装器 | 扫描单测 + 权限拒绝/允许 + Download/U 盘 + 系统安装器真机 smoke |
| 原生卸载 | 资格单测 + 取消/成功真机 smoke；成功只用专门测试包 |
| 开机/服务恢复 | 冷启动、服务回收、应用替换、车机重启 smoke |
| 媒体、音量、HOME | 当前固件公开 API 真机 smoke；私有接口另行方案 |
| 发布签名、release、分发 | 人工门禁、证书核对、版本递增、升级安装与回滚 |

## 3. 敏捷阶段闭环

1. 代码、资源或 Manifest 阶段完成后，AI 依次执行：相关自动检查与测试、Debug 构建、确认设备为 `S56_HQX`、使用明确 APK 路径覆盖安装、启动或触发本阶段入口、观察本阶段主路径和崩溃状态。
2. 最短 smoke 只覆盖本阶段新行为及其直接回归面；不得自动清数据、卸载应用、接受系统授权、重启车机或修改车辆/系统设置。
3. AI 交付已安装版本后，由用户负责更广的视觉匹配、连续操作、真实地图边缘触控、倒车影像/安全警告和主观媒体体验；反馈问题后继续修复并重复本阶段闭环。
4. 用户确认无问题、明确要求提交，或任务开始时已授权本轮完成后提交，才允许收尾提交；阶段 Debug 安装不是发布，完整 V1 交付仍须通过本矩阵全部最终门禁。
5. 车机离线或系统/车辆门禁阻止自动验证时，交付必须写明阻断、已完成证据和压缩后的最小人工动作。

## 4. 自动化用例基线

1. `DrawerGeometryTest`：坐标端点、位移 clamp、`100/101` 与 `299/300` 阈值、取消与异常归位。
2. `AppCatalogFilterTest`：launcher 资格、系统过滤、多入口选择、自身精确判断、`03歌词` 普通资格。
3. `AppOrderReconcilerTest`：更新保位、新装末尾、卸载移除、重装末尾、损坏/重复配置恢复。
4. `DragSessionTest`：内存换位、一次写入、零写入、取消恢复、卸载取消顺序。
5. `PackageEventReducerTest`：`500 ms` 合并、替换语义、拖拽期间延迟刷新。
6. `ApkScannerTest`：扩展名、不可读项、排序、去重、取消与卷失效。
7. 每项实现时必须先建立对应测试文件；不得用弱断言替代真实边界。

## 5. 真机运行级基线

1. 权限：首次启动、悬浮拒绝/允许、未知来源拒绝/允许、存储拒绝/允许都能回到可理解状态。
2. 抽屉：关闭/展开坐标、`600 px` 跟手、`200 ms` 停靠、阈值、手势打断和 `ACTION_CANCEL`。
3. 触摸：地图最右侧按钮保留足够点击区，触发条外透明区域不吞触摸。
4. 层级：状态栏、倒车影像和安全警告在抽屉之上；无法安全自动触发时保留最小人工验收。
5. 应用：枚举准确、每包一个入口、`03桌面` 自身不出现、`03歌词` 正常出现且具备普通卸载目标；点击普通应用时先关闭抽屉，目标应用中触发条仍存在。
6. 排序：实时让位、服务重建保持、更新保位、新装末尾、卸载移除、重装末尾。
7. 安装/卸载：系统页面处理授权与结果；取消恢复；失败不让触发条消失。
8. 快捷控制：HOME、媒体键和音乐流音量在当前车机固件上真实生效。
9. 恢复与稳定：开机、服务回收、应用升级、循环开关/拖拽/安装页无 Window 泄漏和后台扫描。
10. 性能：至少 40 个等价第三方入口，关闭态无轮询/网格绘制，打开、滚动、拖拽无明显连续掉帧。
