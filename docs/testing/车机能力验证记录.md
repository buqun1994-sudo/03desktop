# 车机能力验证记录

## 1. 验证范围

1. 日期：2026-08-13。
2. 设备：`S56_HQX`，Android 9 / SDK 28，物理分辨率 `1920 x 1080`。
3. 方式：首选 Android SDK ADB 的只读 shell 查询；未启动应用、未弹确认页、未安装、未卸载、未授权、未修改系统设置。
4. 普通第三方探测样本：当前设备已安装的 `com.tcrrry.desktoplyrics`。它只作为普通样本，不享受特殊规则。

## 2. 已验证能力

| 能力 | 只读证据 | 结论 |
|---|---|---|
| 第三方应用枚举 | `pm list packages -3` 返回用户安装包；launcher 查询返回可启动 Activity | PackageManager 枚举主链可行 |
| 应用启动 | 样本解析到 `com.tcrrry.desktoplyrics/.MainActivity` | 可用显式 ComponentName 启动 |
| 原生卸载 | `ACTION_DELETE package:` 解析到系统 `UninstallerActivity`；运行级验证发现该直接入口的可点击区域异常 | 本应用改为先进入系统“应用信息”页，再由系统进入原生确认 |
| 原生 APK 安装 | APK MIME `ACTION_VIEW` 解析到系统 `InstallStart` | 可交由系统安装器 |
| 未知来源授权 | `MANAGE_UNKNOWN_APP_SOURCES` 解析到系统应用级授权页 | 首次安装授权入口存在 |
| 下载目录 | `/storage/emulated/0/Download` 存在 | Android 9 下载目录扫描入口存在 |
| U 盘/外部存储 | `sm list-volumes all` 返回已挂载 `public` 卷 `udisk` | 公共外部卷可被系统识别 |

## 3. 尚未验证

1. 倒车影像、车辆安全警告、地图右侧剩余点击区、服务回收和开机恢复不能在当前静止场景中安全自动触发，留为最小人工确认。
2. 媒体控制已在真实播放会话中证明普通应用的全局媒体键不能可靠生效；完整 MediaSession 信息与控制需要通知使用权，该权限不在本项目白名单中，因此 V1 已移除媒体入口。

## 5. 2026-08-17 U 盘增强运行级补充

| 能力 | 实际结果 | 边界 |
|---|---|---|
| 增强文件管理器显式入口 | `org.fossify.filemanager.debug` 的公开 `MainActivity` 可被 `03桌面` 精确解析和启动 | 不依赖通用 Launcher，不扩大到其它包名 |
| 系统 Launcher 隐藏 | `ACTION_MAIN + CATEGORY_LAUNCHER` 查询返回 `No activities found` | 系统设置仍可管理和卸载该普通应用 |
| U 盘直达 | 显式动作 `org.fossify.filemanager.action.OPEN_REMOVABLE_STORAGE` 在 `S56_HQX` 实际进入标题“USB”的 `/storage/udisk` 根目录并显示真实内容 | 路径由增强版通过公开 `StorageManager` 自行解析，`03桌面` 不传 `file://` 或猜测卷名 |
| 安装权限前置 | Debug 覆盖安装后 `READ_EXTERNAL_STORAGE: granted=true`、`REQUEST_INSTALL_PACKAGES: allow`；内置页无授权控件或设置跳转 | 手机安装工具与 Debug 脚本统一负责授权，页面缺失时只报安装流程故障 |
| 内置 APK 安装 | 页面直接列出 Download 测试 APK；点选后系统 `PackageInstallerActivity` 进入前台，返回取消未安装 | `03桌面` 只提供 FileProvider 只读 URI，不静默确认 |
| 休眠任务重启 | 文件管理器关闭后，从网格可重新打开内部存储；从安装页连续两轮均重新进入 USB 根目录 | 精确契约使用 `NEW_TASK | CLEAR_TASK`，只清 Activity 任务，不清数据或权限 |

## 6. 2026-08-20 包名迁移后状态

1. Android 身份已迁移到 `com.ninepointnine.desktop`，staging / production 签名 APK 的包名、单 signer、v2 和证书摘要已在本机完成核对。
2. 本节之前的车机记录均发生在历史包 `com.tcrrry.desktop` 上；新包尚未安装到 `S56_HQX`，因此旧包的授权、进程、悬浮服务和 AccessibilityService 结论不能宣称新包已通过。
3. 新包首次安装需要重新取得悬浮窗、Download / 未知来源 AppOp 和全局返回服务授权；本轮未执行安装、卸载、清数据或系统设置修改。

## 7. 可复跑入口

1. 环境与设备基线：`./scripts/check-android-env.sh --device`。
2. 系统能力解析：`./scripts/check-device-capabilities.sh --package <普通第三方应用包名>`。
3. 脚本只证明系统入口可解析，不证明最终 UI、权限时序或用户闭环已经可用。
