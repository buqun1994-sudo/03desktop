# 设计规则

## 1. 默认规则

1. 设计应服务目标用户和核心任务，不用装饰替代信息架构。
2. 页面、组件、状态和交互应形成稳定系统，不为单次页面复制孤立样式。
3. UI 文案应表达用户可感知结果，不解释内部实现。
4. 响应式、可访问性、空态、加载态、错误态和权限不足态应进入验收。
5. 多语言界面必须按当前界面语言显示语言名称和用户任务，不向最终用户暴露 locale code；最长翻译、换行、按钮稳定尺寸和 RTL 适用性必须进入视觉验收。

## 2. 03桌面项目规则

1. 触发条件：修改抽屉 UI。动作：以 `S56_HQX` 的 `1920 x 1080` 车机界面为唯一画布，复用已从原车应用中心验证的应用网格视觉语言；深浅模式只读取 `Configuration.uiMode` 并由 `values` / `values-night` 提供语义色，保持四列、固定触控区和克制动效。验证：构建后采集目标车机截图，检查深浅画面、坐标、顶部间距和长名称。边界：V1 不做手机/平板响应式，也不增加搜索、收藏或说明型面板；设置双栏与应用网格属于不同页面模式，不混用背景和内容结构。
2. 触发条件：修改把手、悬浮入口或抽屉停靠位置。动作：使用原车资源真值对应的 `6 x 150 px`、`3 px` 圆角细竖线，浅色为 `#2B000000`、深色为 `#2BFFFFFF`；真实把手 Window 必须在面板之前完成层级准备、最后挂载，并在正常开合期间只更新坐标，不得移除、重加或切换镜像。拖拽过程允许透明运动容器延伸到屏幕物理边缘，但展开稳定态的软件内容固定为 `x=1290..1890`，右侧保留 `30 px`，不得为了边缘入场修改最终停靠点。验证：自动断言运动首帧和稳定间距，再由用户检查打开拖拽、松手停靠、回拉和主题切换时竖条连续无闪动。边界：不使用文字按钮、圆形悬浮按钮或装饰卡片；可见把手不能扩大实际触摸窗或遮挡系统安全界面。
3. 触发条件：修改抽屉页面生命周期或打开阈值。动作：服务建立时将完整页面、目录和首屏图标离屏预热；关闭后把同一面板 Window 完整移到屏幕外并禁止触摸，根页面保持可布局状态且不切换 visibility，保留已绑定状态供下次首帧直接使用。正常打开手势一旦越过系统方向识别阈值，松手即展开；`300 px` 中点只用于动画异常或未知中间态恢复。验证：用户连续开关确认页面、滚动位置和竖条均不闪动，并验证最短有效左滑松手自动展开。边界：冻结态无轮询、无动画、无持续重绘和无屏内合成；首次预热或包安装、更新、卸载事件允许触发离屏更新，系统仍可冻结或回收整个进程，内存压力继续通过现有图标缓存回收入口处理。
4. 触发条件：应用名称或状态文案变化。动作：名称最多两行、末尾省略，不动态缩小字体；状态只说明任务、结果和下一步。验证：最长名称、空态、权限拒绝和失败提示截图。边界：不向用户显示包名、Intent、权限常量或调试信息。
5. 触发条件：拖拽交互变化。动作：长按成功后将当前应用在 `100 ms` 内缩放到 `1.06` 倍并临时提高网格绘制层，不增加发亮底框、描边、旋转或弹跳；RecyclerView 项实时让位，底部安装动作原位互斥替换为卸载目标。安装和卸载的图标文字直接显示在抽屉表面，不使用大面积底板；命中卸载区只增强图标文字颜色并轻微放大。松手或取消必须恢复原尺寸、原绘制层、原有效位置和安装动作。验证：用户连续拖拽并检查应用始终高于底部动作、安装/卸载不同时出现、取消后完整恢复；里程碑或明确要求时再录屏。边界：视觉缩放不能改变 cell 固定尺寸、卸载命中矩形或底部动作区整体布局。
6. 触发条件：抽屉处于展开稳定态。动作：监听非模态悬浮窗的窗外首次按下并立即启动收起，原始点击继续由下层车机界面处理；右侧把手仍属于本软件交互区。验证：交付用户在抽屉外点击一个有可见动作的原车控件，同一次点击必须既触发原车动作又使抽屉收起。边界：不得增加透明全屏触摸层，不得扩大面板或把手窗口来截获窗外事件。
7. 触发条件：调整抽屉信息架构。动作：应用名称与网格必须是首屏主角，顶部保留 `42 px` 间距和 `84 px` 标题触控层；安装 APK 只能作为底部次级动作，不得充当页头、品牌名或首屏最大视觉元素。验证：目标车机截图中标题、首行图标、滚动网格和底部动作区层级清楚，任何两个功能区都不重叠。边界：不得用一个工具动作冒充产品身份，也不得同时展示安装、卸载和无效快捷区抢占网格空间。
8. 触发条件：复用 `03歌词` 已沉淀的原车 UI 规范。动作：只提取具有资源绑定与运行态证据的数值和语义，集中写入本项目资源；保留应用中心来源的 `42 / 84 / 18 px` 页面节奏与 `108 px` 全屏图标基准，右侧小窗口将运行图标适配为 `96 px`、标签为 `24 sp`、行步长为 `194 px`，标题使用 `38 sp` 加粗字重。验证：资源引用、目标密度 `141 dpi` 与车机截图三者一致。边界：不得复制 `03歌词` 源码、包名、签名或原车私有资产，也不得把设置页专用双栏数值误用到应用网格。
