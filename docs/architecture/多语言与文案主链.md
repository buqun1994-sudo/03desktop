# 多语言与文案主链

## 1. 当前范围

1. V1 唯一界面语言为简体中文，fallback 也是简体中文；暂不提供运行时语言切换。
2. 所有用户可见文案必须进入 Android `res/values/strings.xml`，不得散落在 Kotlin、布局、错误分支或系统 Intent 组装代码中。
3. 应用名称、APK 名称和系统错误属于外部内容，按系统提供结果展示并执行长度约束；不得当作项目固定文案复制进资源。

## 2. Owner 与格式

1. 文案 owner：`app/src/main/res/values/strings.xml`。
2. UI 只通过 `@string/...` 或 `getString(...)` 读取；格式参数使用 Android 格式化占位符并声明 `formatted` 语义。
3. 用户只看到任务、状态、结果和下一步，不看到包名、Intent、广播、权限常量、异常类或 ADB 信息。
4. 新增中文文案必须从当前 UTF-8 XML 源码编辑，禁止依据终端乱码、截图转写或 Unicode 转义重建。

## 3. 未来扩展门禁

1. 新增第二种语言时，使用 Android `values-<locale>/strings.xml`，并把 locale、fallback、缺 key 和格式参数一致性纳入机械检查。
2. 在第二种语言真正进入范围前，不维护空翻译文件，不把模板的 JSON locale 方式强加给 Android 资源系统。
3. 多语言施工必须补 fallback 与非 fallback 的真机启动 smoke，并检查应用长名称、按钮与错误提示不重叠。

## 4. 当前验证

1. Android Lint 检查布局硬编码文案和资源问题。
2. `rg -n 'android:text="' app/src/main/res --glob '*.xml' | rg -v 'android:text="@string/'` 用于专项审查；颜色、数值和系统属性不属于文案。
3. 关键页面真机 smoke 验证中文可读、长应用名省略/换行和错误提示不遮挡操作区域。
