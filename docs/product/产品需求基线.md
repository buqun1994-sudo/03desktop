# 产品需求基线

## 1. 产品定位

1. 产品名称：`03桌面`。
2. 一句话定位：Android 9 车机上补齐第三方应用展示与管理能力的轻量右侧应用抽屉。
3. 目标用户：使用 `S56_HQX` 车机、需要找到和管理原厂应用中心未展示第三方应用的车主或乘员。
4. 核心问题：原厂应用中心不能稳定展示全部用户安装且可启动的应用，用户缺少轻量、常驻、无需外部设备的统一入口。
5. 非目标用户：应用商店运营者、车厂系统管理员、需要 root/ROM 改造或车辆控制能力的用户。
6. 独立产品身份：`03桌面` 与 `03歌词` 不共享包名、签名、源码、排序特权或卸载保护；`03歌词` 始终按普通第三方应用处理。

## 2. 核心用户路径

1. 开机恢复：车机启动后，右侧边缘触发条自动恢复；正式运行不依赖手机、电脑或 ADB。
2. 打开与启动：用户从屏幕右侧向左滑动，面板跟手展开；点击抽屉外任意车机界面时，抽屉自动收起且原始点击继续由下层界面处理；点击任一顶层动作后面板先关闭，再启动目标窗口，右侧触发条继续存在。普通第三方应用由 Activity metadata 声明是否为 iCAR 标准浮窗；内置安装页、增强文件管理器、卸载系统页及后续顶层设置页固定加入全局互斥。当前已有标准浮窗时先退回桌面再启动，关闭目标后不得回弹旧系统窗口。
3. 全局返回：抽屉关闭时，用户轻点右侧触发条执行一次 Android 系统返回；向左滑动仍只负责展开抽屉。该能力需要用户在系统侧手动启用“03桌面全局返回”，未启用或服务失效时轻点不执行返回，但不影响滑动打开抽屉。
4. 管理顺序：用户长按图标拖动，网格实时让位；松手后只保存一次最终顺序。
5. 卸载应用：用户把普通第三方应用拖入卸载目标；若当前有其它标准浮窗，先退回桌面，再打开系统应用详情页并由系统继续进入原生卸载确认。取消时应用保留原位置，成功后由系统包变化事件刷新列表。
6. 安装 APK：手机安装工具在安装 `03桌面` 时统一授予 Download 读取和未知来源安装资格；抽屉底部始终显示“安装 APK”，点击后进入内置页面并直接扫描 Download 中的 APK，页面不再显示或跳转任何重复授权入口。用户点选后直接由 Android 系统安装器继续处理；若安装前置授权异常缺失，只提示重新通过手机安装工具授权。精确包名 `org.fossify.filemanager.debug` 的车机增强版文件管理器已安装、启用且声明契约版本 1 时，安装页额外显示“打开 U 盘”，点击后直达当前挂载 U 盘根目录；增强软件缺失或版本不兼容不影响 Download 安装主链。

## 3. V1 功能边界

1. 展示所有用户安装、具有可启动入口的普通第三方应用；排除系统应用、更新后的系统应用、后台服务、插件和无启动入口组件。对装在普通应用区的原车融合应用，只有已验证的车型/固件、精确包名、官方签名和车载专用组件全部命中时才排除；任一证据缺失时按普通应用展示。
2. 同包存在多个启动入口时只展示一个确定的主入口；图标和名称来自系统包管理器。
3. 应用网格默认四列并占据页面主体，可上下滚动；底部安装动作不参与网格排序，拖拽时同一动作位互斥替换为卸载目标。
4. 应用更新保持原位置；新安装追加末尾；卸载移除；卸载后重装按新应用追加末尾。
5. 面板只通过公开 Android 能力执行启动、安装和卸载。
6. 开机、应用升级和服务回收后按 Android 9 允许的前台服务机制恢复边缘触发条。
7. 抽屉关闭时只保留轻量边缘触发窗口，不持续绘制网格、不轮询包状态。
8. 抽屉从有效展开开始到完全收回屏幕外期间，通过通用绑定租约声明桌面表面被占用；协议提供方自行响应，未安装提供方不得影响抽屉使用。
9. 全局返回服务只响应本应用进程发出的单次返回请求，调用公开 `GLOBAL_ACTION_BACK`；不读取窗口内容、不处理无障碍事件、不监听按键、不执行手势，也不提供主页或任务列表动作。

## 4. 已确认的自身处理

1. V1 在自身应用网格中隐藏 `03桌面`，只允许按精确包名 `com.tcrrry.desktop` 识别自身。
2. V1 不从自身悬浮面板提供 `03桌面` 的卸载拖放目标。
3. 这不形成系统级保护：用户仍可通过 Android 设置、原厂应用管理或其它标准入口正常卸载 `03桌面`。
4. `03歌词` 的包名 `com.tcrrry.desktoplyrics` 不命中自身规则，必须与其它普通第三方应用一样显示、排序并支持原生卸载确认。
5. 车机增强版文件管理器只按精确包名 `org.fossify.filemanager.debug` 和公开 `MainActivity` 识别：即使它没有通用 Launcher 入口，`03桌面` 仍显式把它合成到应用网格中，参与普通显示、排序、启动和卸载。
6. “仅在 03桌面展示”由增强版移除 `MAIN + LAUNCHER` 入口、`03桌面` 显式启动公开 Activity 实现；这不是系统级隐藏或卸载保护。用户仍可通过 `03桌面` 拖拽卸载，或通过 Android 设置和原厂应用管理卸载。

## 5. V1 明确不做

1. 不建设应用商店、搜索、收藏、分类、推荐、排行或使用频率排序。
2. 不联网检查第三方应用版本，不下载 APK，不建设通用文件浏览器；只在用户进入内置安装页期间读取并扫描 Download 目录，离开页面即取消扫描和清空结果。U 盘通用浏览由可选文件管理器承担。
3. 不静默安装或卸载，不绕过 Android 原生确认，不自行管理其它应用权限、数据或进程。
4. 不提供天气、Wi-Fi、蓝牙、空调、车窗、车锁、座椅或驾驶辅助控制。
5. 除已确认的单次全局返回外，不使用 root、其它无障碍模拟、ADB 常驻、持续截图、动态模糊、实时壁纸采样或车厂私有接口猜测。
6. 不修改车机 ROM，不成为默认 HOME，不替换原厂桌面，不直接控制车辆安全能力。
7. 不为手机、平板或其它分辨率提供 V1 适配；唯一验收设备是 `S56_HQX` 的 `1920 x 1080` Android 9 车机。
8. V1 不提供媒体卡片或媒体控制。全局媒体键已在目标固件上证明不能可靠控制当前会话；读取歌曲、封面、播放状态和进度需要通知使用权，而该权限不在本项目白名单内。

## 6. V1 成功标准

1. 右侧触发、跟手拖动、`200 ms` 停靠、关闭与恢复阈值均符合固定坐标基线；关闭态轻点触发条只执行一次系统返回，向左滑动仍展开抽屉；点击抽屉外区域时自动收起且不阻断原车界面的原始点击。
2. 普通第三方应用能被准确枚举、启动、排序、卸载和安装刷新，`03歌词` 与车机增强版文件管理器均不享受卸载保护；文件管理器只在 `03桌面` 网格显式展示，增强版存在时安装页可直达 U 盘；已验证的原车融合微信不在列表出现，手机版微信、改签版本和其它腾讯应用不得被误隐藏。
3. 地图最右侧按钮仍可点击；面板低于状态栏、倒车影像和安全警告，不破坏原厂桌面或其它应用交互。
4. 开机后无需外部设备即可恢复服务与触发条；异常退出不影响地图和原厂功能。
5. 安装几十个第三方应用后，打开、滚动和拖拽仍流畅；关闭状态没有包扫描轮询和网格持续绘制。
6. 自动化测试为状态机、排序协调、事件合并和配置提供基础保护；最终车机体验由用户验证系统窗口、权限、安装/卸载确认与安全界面层级。

## 7. 验收口径

1. 日常功能切片完成 `assembleDebug` 和命中的直接相关测试后即可交付，不等待完整 V1 或全量回归。
2. 用户是运行级验收的主要执行者，按本轮交付路径验证界面、手势、启动、排序、安装/卸载和包刷新，并把现象直接反馈给 AI 修复。
3. 里程碑收口、准备提交/发布或用户明确要求时，再执行完整单测、Lint、Debug 构建和本次范围内的真机验收清单；危险设备动作继续单独确认。
