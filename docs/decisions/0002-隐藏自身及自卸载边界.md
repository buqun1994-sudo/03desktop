# 决策 0002：隐藏自身及自卸载边界

## 1. 状态

1. 日期：2026-08-13。
2. 状态：已采纳；用户于 2026-08-13 明确确认隐藏自身，2026-08-20 随包名迁移更新精确身份。

## 2. 决策

1. V1 在 `03桌面` 自身网格中隐藏 `com.ninepointnine.desktop`。
2. V1 不从自身悬浮面板提供 `03桌面` 的卸载拖放目标。
3. 不做系统级保护：Android 设置、原厂应用管理或其它标准入口仍可正常卸载 `03桌面`。

## 3. 理由

1. 点击自身不会产生新的用户任务，只会重复打开承载面板的进程。
2. 自卸载时，发起流程的服务和窗口正是待卸载对象；即使原生确认页能够打开，取消/成功后的面板恢复语义比普通应用更复杂，且更容易误触。
3. 隐藏自身只影响当前产品的信息架构，不应扩大为不可卸载或特殊系统身份。
4. `03歌词` 与其它普通第三方应用不受这条决策影响，必须支持显示、排序和原生卸载确认。

## 4. 施工锚点

1. 枚举规则只按精确包名 `com.ninepointnine.desktop` 排除自身；禁止按开发者、签名或包名前缀排除其它应用。
2. 卸载资格复用同一 `isSelf` 领域字段，禁止在拖拽 UI 再维护第二套特殊判断。
3. 单元测试必须证明 `com.ninepointnine.desktoplyrics` 与其它普通第三方应用仍为可显示、可排序、可卸载。
