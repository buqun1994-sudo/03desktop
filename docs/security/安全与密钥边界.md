# 安全与密钥边界

## 1. 产品安全边界

1. `03桌面` 是普通第三方 Android 应用，不获取 root、不修改 ROM、不成为设备所有者、不使用无障碍模拟操作。
2. 正式运行不依赖 ADB、电脑、手机或网络；V1 不声明 `INTERNET` 权限。
3. 应用管理只通过 PackageManager、Android 系统“应用信息”页和原生安装/卸载确认页；不得静默安装、静默卸载、自行删除其它应用或清除其数据。
4. 悬浮层必须使用普通 `TYPE_APPLICATION_OVERLAY`，并通过真机证明低于状态栏、倒车影像和车辆安全警告。
5. 抽屉启动第三方标准浮窗以及 03桌面安装页、卸载系统页等顶层窗口时，互斥链只读取已验证的 Secure 状态并使用公开 HOME Intent；安装任务内部需要返回结果的授权与系统安装子页面保留父子关系。桌面表面占用只通过公开 PackageManager 查询和 exported bound service 绑定生命周期表达，不调用 Binder 业务方法。

## 2. 权限白名单

1. `SYSTEM_ALERT_WINDOW`：用户从系统逐应用页面授权，用于右侧触发条和抽屉。
2. `FOREGROUND_SERVICE`：Android 9 常驻触发服务，必须显示真实前台通知。
3. `RECEIVE_BOOT_COMPLETED`：只在悬浮权限已存在时恢复服务，不后台弹权限页。
4. `REQUEST_INSTALL_PACKAGES`：用户点击 APK 后进入系统安装器；未知来源授权由系统决定。
5. `READ_EXTERNAL_STORAGE`：仅 Android 9 安装页面按需读取 Download；U 盘优先使用系统 SAF 逐卷授权。

## 3. 明确禁止权限与能力

1. 禁止 `QUERY_ALL_PACKAGES`、`MANAGE_EXTERNAL_STORAGE`、`WRITE_EXTERNAL_STORAGE`、安装/卸载系统特权和忽略电池优化。
2. 禁止无障碍、通知监听、录屏/截图、位置、联系人、相机、麦克风、蓝牙、Wi-Fi 管理和车辆控制权限；因此 V1 不读取 MediaSession 的歌曲、封面、状态或进度，也不展示伪媒体控制区。
3. 禁止隐藏 API、反射、车厂私有广播猜测、shell 命令或 ADB 作为运行旁路。
4. 新权限必须先更新 V1 方案、本文、配置检查白名单和验证矩阵，并取得用户确认。
5. 禁止申请 `WRITE_SECURE_SETTINGS`、写入或伪造 `window_mode`，禁止任务枚举、force-stop、固定 sleep、周期轮询，以及按歌词包名建立专用联动。

## 4. 文件与隐私

1. APK 扫描只在用户主动进入安装页面时运行，离开页面立即取消；不后台索引、不联网、不上传。
2. 只读取文件显示名、URI、大小、修改时间和系统安装所需内容；日志不得记录个人文件路径或 APK 内容。
3. Storage Access Framework 的持久 URI 权限只绑定用户主动选择的外部卷；卷消失或授权失效时清理本地记录。
4. 应用列表和排序保存在应用私有 SharedPreferences，不包含账号、位置、联系人或使用频率。

## 5. 本机环境与签名

1. 禁止提交：`local.properties`、`android-env.local.properties`、`keystore.properties`、`*.jks`、`*.keystore`、密码、私钥、token、SDK/JDK/ADB 二进制、Gradle 缓存、APK/AAB、日志、截图和录屏。
2. `local.properties.example`、`android-env.example.properties` 和 `keystore.properties.example` 只能包含逻辑占位，不能写个人电脑路径或真实密码。
3. `03桌面` 必须新建独立 release 证书并仓库外至少双份备份；不得复用 `03歌词` 或其它产品签名。
4. 创建/替换签名、生成正式 release、安装到正式车机或对外分发均属于人工门禁，未经明确指令不执行。

## 6. 设备写操作门禁

1. 环境和能力检查脚本只读，不安装、不卸载、不启动目标应用、不授权、不改设置。
2. Debug APK 安装、清数据、重启、授权、真实安装/卸载测试必须在对应运行级验证范围内明确执行并记录恢复方式。
3. `03歌词` 可作为普通枚举、启动解析和“打开系统应用信息页后退出”的卸载样本，但不得在验证中实际卸载。
