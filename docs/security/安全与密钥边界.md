# 安全与密钥边界

## 1. 产品安全边界

1. `03桌面` 是普通第三方 Android 应用，不获取 root、不修改 ROM、不成为设备所有者。唯一无障碍能力是用户明确启用的全局返回服务，只调用公开 `GLOBAL_ACTION_BACK`。
2. 正式运行不依赖 ADB、电脑、手机或网络；V1 不声明 `INTERNET` 权限。
3. 应用管理只通过 PackageManager、Android 系统“应用信息”页、内置 APK 安装页和增强文件管理器的公开显式入口；手机安装工具在安装阶段授予 `03桌面` 的 Download 读取和未知来源安装资格，页面只读取用户选择的 APK 并交给系统安装器，不得静默安装、静默卸载、自行删除其它应用或清除其数据。
4. 悬浮层必须使用普通 `TYPE_APPLICATION_OVERLAY`，并通过真机证明低于状态栏、倒车影像和车辆安全警告。
5. 抽屉启动第三方标准浮窗、内置安装页、增强文件管理器和卸载系统页等顶层窗口时，互斥链只读取已验证的 Secure 状态并使用公开 HOME Intent。桌面表面占用只通过公开 PackageManager 查询和 exported bound service 绑定生命周期表达，不调用 Binder 业务方法。
6. 全局返回服务配置固定为 `canRetrieveWindowContent=false`、`canRequestFilterKeyEvents=false`、`canPerformGestures=false`；事件回调不读取数据，不创建无障碍悬浮层，不扩展主页、任务列表、媒体或自动点击能力。

## 2. 权限白名单

1. `SYSTEM_ALERT_WINDOW`：用户从系统逐应用页面授权，用于右侧触发条和抽屉。
2. `FOREGROUND_SERVICE`：Android 9 常驻触发服务，必须显示真实前台通知。
3. `RECEIVE_BOOT_COMPLETED`：只在悬浮权限已存在时恢复服务，不后台弹权限页。
4. `READ_EXTERNAL_STORAGE`：Android 9 上由手机安装工具或 Debug 覆盖脚本在安装阶段统一授予，仅用于用户进入安装页后读取公共 Download；页面自身不请求权限，不用于 U 盘或后台文件管理。
5. `REQUEST_INSTALL_PACKAGES`：由手机安装工具或 Debug 覆盖脚本在安装阶段统一授予 AppOp；仅在用户点选 APK 后调用系统安装器，页面不跳转授权设置，不静默安装。
6. `AccessibilityService`：不属于 `<uses-permission>` 申请项，由用户在系统侧手动启用；仅为关闭态触发条提供一次系统返回。

## 3. 明确禁止权限与能力

1. 禁止 `QUERY_ALL_PACKAGES`、`MANAGE_EXTERNAL_STORAGE`、`WRITE_EXTERNAL_STORAGE`、安装/卸载系统特权和忽略电池优化；普通 `REQUEST_INSTALL_PACKAGES` 不得扩张到后台或静默安装。
2. 禁止把全局返回服务扩展为窗口内容读取、按键监听、手势执行、自动点击、主页、任务列表或媒体控制；同时禁止通知监听、录屏/截图、位置、联系人、相机、麦克风、蓝牙、Wi-Fi 管理和车辆控制权限。因此 V1 不读取 MediaSession 的歌曲、封面、状态或进度，也不展示伪媒体控制区。
3. 禁止隐藏 API、反射、车厂私有广播猜测、shell 命令或 ADB 作为运行旁路。
4. 新权限必须先更新 V1 方案、本文、配置检查白名单和验证矩阵，并取得用户确认。
5. 禁止申请 `WRITE_SECURE_SETTINGS`、写入或伪造 `window_mode`，禁止任务枚举、force-stop、固定 sleep、周期轮询，以及按歌词包名建立专用联动。

## 4. 文件与隐私

1. `03桌面` 只在安装页可见期间读取公共 Download 目录中的文件名、大小、修改时间和 APK 内容 URI；不读取 U 盘、不持有 Storage Access Framework 授权、不删除文件。文件管理器作为独立应用自行承担通用文件与 U 盘访问权限边界。
2. 应用列表和排序保存在应用私有 SharedPreferences，不包含账号、位置、联系人、文件路径或使用频率。

## 5. 本机环境与签名

1. 禁止提交：`local.properties`、`android-env.local.properties`、`keystore.properties`、`signing.properties`、`*.jks`、`*.keystore`、密码、私钥、token、SDK/JDK/ADB 二进制、Gradle 缓存、APK/AAB、日志、截图和录屏。
2. `local.properties.example`、`android-env.example.properties` 和 `keystore.properties.example` 只能包含逻辑占位，不能写个人电脑路径或真实密码。
3. `03桌面` 的 staging 与 production 分别使用独立证书，不得互相复用，也不得复用 `03歌词`、`03投屏` 或其它产品签名。Cloud 只接收公开证书摘要和临时构建注入，不持有仓库内私钥。
4. 两套证书已经按用户授权创建；后续替换、吊销、写入云端密钥系统、安装 production 包或对外分发仍属于人工门禁，未经明确指令不执行。
5. 即使只通过自有网页向少量用户侧载，也必须使用长期受控的 production 证书；默认 Debug 证书只用于开发，staging 证书只用于测试。新包首次安装需要重新取得系统授权，后续各环境必须保持对应证书不变并递增 `versionCode`。
6. 对外分发 GPLv3 的 Fossify 修改版时，必须同时提供对应上游提交、完整改造补丁和许可证获取入口；仓库内可复现资产位于 `vendor/fossify-file-manager-car/`。文件管理器的正式 Release 签名与 `03桌面` 独立管理。

## 6. 设备写操作门禁

1. 环境和能力检查脚本只读，不安装、不卸载、不启动目标应用、不授权、不改设置。
2. Debug APK 安装、清数据、重启、授权、真实安装/卸载测试必须在对应运行级验证范围内明确执行并记录恢复方式。
3. 自动卸载验证默认使用可删除测试包，不得擅自选择真实业务应用。用户在当前任务中明确指定普通第三方应用的精确包名并要求卸载，即视为已打开该目标的人工门禁；确认卸载数据影响且核对可恢复 APK 后应执行真实卸载，不得以自动测试或调试阶段保护为由拒绝。`03歌词` 与其它普通第三方应用相同，不享受永久卸载保护。
